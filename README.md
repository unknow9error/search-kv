# Meken — поиск квартиры через разговор

Нативные приложения для **iOS 18+** и **Android 8+**, общий сервер. Пользователь начинает с «хочу квартиру», уточняет пожелания, получает карточки по мере поступления данных, сравнивает варианты и проверяет наличие у застройщика.

**Реальная интеграция:** BI Group. Поддержаны UUID городов Астана, Алматы, Шымкент, Атырау и Караганда; сквозной live-тест выполнен для Астаны. Остальные застройщики подключаются отдельными адаптерами. Это не заявление о покрытии всего рынка.

## Что реализовано

- Android / Kotlin / Jetpack Compose: подбор, фильтры, сравнение, карточки, избранное, история и удаление данных через общий `/v1` API; защищённая сессия Android Keystore, кеш и восстановление SSE. [Сборка Android](android/README.md), [проверка мобильной архитектуры](docs/MOBILE_ARCHITECTURE.md).
- Полная история, идемпотентное создание диалога и код доступа для восстановления/переноса одного профиля между iOS и Android подготовлены в новом backend. Release обеих платформ закреплён на `https://194.238.43.134`. Новый backend ждёт разрешения на production backup/restore перед выкаткой; старый API поддерживается через capabilities.

- Swift 6 / SwiftUI: чат, фильтры, карточки с планировками, карта ЖК, сравнение до трёх квартир, избранное, история, удаление данных. Авторизация без регистрации; секрет сессии хранится в Keychain, избранное кешируется через SwiftData.
- FastAPI: версия API `/v1`, поток SSE, повторное чтение событий, идемпотентные сообщения, изоляция пользователей, ограничения запросов и расходов ИИ.
- PostgreSQL / SQLAlchemy / Alembic: каталог, статусы, время получения сведений, инфраструктура, документы, диалоги и история импорта. Redis: общие блокировки, лимиты и ограничение повторных запросов.
- Адаптер BI Group: фильтры по официальной OpenAPI-схеме, выдача страницами, отдельная проверка квартиры, связь с ЖК/бигвиллем, цены без предположений о праве на скидку.
- Инфраструктура **сначала из данных застройщика**: отдельные факты ЖК и бигвилля, состояния `operating / planned / under_construction / unknown`, источник, цитата, заявленный срок и дата пересмотра. OSM — необязательное дополнение; включён небольшой проверенный контекст Aisar со страницы застройщика. Отсутствие записи не означает отсутствие школы.
- RAG: поиск по актуальным памяткам и структурированным фактам, ссылки на источники. Модель выбирает план и релевантные материалы; цены, наличие и расстояния формируются кодом.
- Контейнеры, CI, миграции, метрики, health checks, непривилегированный runtime, инструкция развёртывания и восстановления.

## Где вызывается ИИ

| Операция | Вызовы модели |
|---|---:|
| GET карточки, фильтры, избранное | 0 |
| Получение/обновление квартир застройщика | 0 |
| Расчёт расстояний, отбор, сортировка | 0 |
| Стартовое «хочу квартиру», готовые фильтры, кнопки объяснения/сравнения | 0 |
| Понимание свободного сообщения | До 1 |
| Общий вопрос с поиском по базе знаний | До 2 за сообщение, включая понимание запроса |
| Повторная выдача сохранённого ответа | 0 |

ИИ включается явно. Без ключа приложение работает в обозначенном базовом режиме; это не выдаётся за полноценное понимание произвольного текста. При ошибке модели остаются простые правила и форма фильтров.

## Быстрый запуск с BI Group

Требуются Python 3.12+, Docker, Xcode 16+ и XcodeGen. Версии Python-зависимостей закреплены в lock-файлах.

```sh
python3 scripts/bootstrap-env.py
docker compose up --build -d
```

API будет доступен на `http://127.0.0.1:8001`. `bootstrap-env.py` создаёт случайные локальные секреты и **не перезаписывает** существующий `.env`. Миграции и встроенные памятки применяются отдельным контейнером до старта API. Worker выполняет ограниченные фоновые проходы каталога; персональные запросы дополнительно обновляют нужную выборку.

```sh
xcodegen generate --spec ios/project.yml
open ios/Meken.xcodeproj
```

В Xcode выберите схему **Meken** и iPhone. Debug и Release по умолчанию используют сервер `https://194.238.43.134`. Для локального API измените build setting `MEKEN_API_BASE_URL` на `http://127.0.0.1:8001` в Debug или передайте его в `xcodebuild`. Ключ ИИ в приложение не передаётся.

iOS-проект настроен для существующего приложения [Meken в App Store Connect](https://appstoreconnect.apple.com/apps/6818146064): Bundle ID `kz.unknown.meken`, Apple Developer Team `8885RF248C`, версия `1.0`, сборка `1`. Эти значения и HTTPS endpoint сохранены в `ios/project.yml`. Для загрузки сборки нужны доступная в Xcode учётная запись этой команды и подписанный архив. Настройка идентификаторов и адреса API сама по себе не загружает сборку в TestFlight.

### Сервер без Docker для разработки

```sh
cd backend
python3.12 -m venv .venv
.venv/bin/pip install -r requirements-dev.lock
.venv/bin/pip install -e . --no-deps
cp .env.example .env
```

Для реального каталога в `backend/.env` задайте:

```dotenv
MEKEN_ENV=development
MEKEN_DATABASE_URL=sqlite+aiosqlite:///./meken.sqlite3
MEKEN_AUTO_CREATE_SCHEMA=false
MEKEN_PROVIDER_CONFIG=data/providers.bi-group.json
MEKEN_AI_ENABLED=false
```

```sh
.venv/bin/python -m app.migrate
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8001 --no-access-log
```

SQLite предназначена для разработки. Production-режим требует PostgreSQL, Redis, явных миграций, метрик с токеном и опубликованных ссылок на политику и условия.

### Включить ИИ

В серверном `.env` задайте `MEKEN_AI_ENABLED=true`, `MEKEN_OPENAI_API_KEY` и доступный вашему аккаунту `MEKEN_AI_MODEL`. Начальное значение — `gpt-4.1-mini`; поставщик и модель изолированы в `backend/app/services/assistant.py`. Выбор модели для релиза нужно подтвердить на реальных русскоязычных запросах и бюджете аккаунта. Live-вызовы платной модели в этой работе не выполнялись.

## Проверки

```sh
cd backend
.venv/bin/ruff check app tests
.venv/bin/pytest -q
cd ../ios/MekenCore
swift test
```

Настоящие PostgreSQL и Redis, с отдельной временной схемой на каждый тест:

```sh
docker compose -f compose.yml -f infra/compose.test.yml up -d db redis
backend/.venv/bin/python scripts/test-integration.py
```

Нативные UI-тесты требуют работающий API на порту 8001. Запускайте `Test` схемы Meken в Xcode. В CI обычная сборка и unit-тесты не обращаются к BI Group. Live-интеграция запускается отдельно, осознанно:

```sh
cd backend
.venv/bin/python ../scripts/smoke_live.py
```
